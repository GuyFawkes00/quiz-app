# Quiz App

Интерактивное веб-приложение для создания и проведения квизов в режиме реального времени. Организатор создает комнату, добавляет вопросы и управляет ходом игры, а участники подключаются по уникальному коду и отвечают на вопросы синхронно.

## Стек технологий

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Real-time взаимодействие:** Socket.IO (WebSocket)

## Основные возможности

- **Реальное время:** Мгновенная синхронизация состояний между организатором и участниками
- **Гибкая настройка:** Организатор может задавать правила, время на ответ и категории вопросов
- **Разнообразие вопросов:** Поддержка текстовых вопросов и вопросов с изображениями (по URL), а также логика одиночного и множественного выбора
- **Таймер:** Визуальный обратный отсчет времени для каждого вопроса
- **Лидерборд:** Автоматический подсчет баллов и вывод таблицы результатов в конце квиза
- **Защита от дубликатов:** Система не позволяет участникам регистрироваться в комнате с одинаковыми именами

## Запуск

### Предварительные требования
- Установленный [Node.js](https://nodejs.org/) (версия 18 или выше)

### Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта
2. Запуск серверной части (Backend):
Откройте терминал в папке server, установите зависимости и запустите сервер:
   cd server
   npm install
   npm start
Сервер запустится на порту 3001
3. Откройте новый терминал, перейдите в папку client, установите зависимости и запустите клиент:
   cd client
   npm install
   npm run dev
Приложение откроется по адресу http://localhost:5173

### Проверка

1. Откройте http://localhost:5173 в браузере
2. В первой вкладке войдите как Организатор, создайте комнату, добавьте вопросы и запустите квиз
3. Откройте вторую вкладку (или режим инкогнито), войдите как Участник и введите код комнаты, чтобы пройти квиз в реальном времени
